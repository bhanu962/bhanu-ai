# Bhanu AI public website

This is a static GitHub Pages website for the Bhanu AI developer-assistant plugin.

## Publish with GitHub Pages

1. Create a public GitHub repository named `bhanu-ai` under the `bhanu962` account.
2. Upload all files in this folder to the repository root (not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub finishes deployment, verify:
   - `https://bhanu962.github.io/bhanu-ai/`
   - `https://bhanu962.github.io/bhanu-ai/support.html`
   - `https://bhanu962.github.io/bhanu-ai/privacy.html`
   - `https://bhanu962.github.io/bhanu-ai/terms.html`

## Before publishing

- The site does not add a contact form, analytics, cookies, or a backend.
